# Pizarra Táctica Pro

Pizarra para entrenadores: fútbol 11 o sala, formaciones por equipo, arrastre de fichas, trazado de destinos y reproducción animada de la jugada. Funciona con mouse o táctil y se adapta al celular.

## Tecnologías
- HTML
- CSS
- JavaScript

## Cómo ejecutarlo
Abre `index.html` en el navegador.
